# Описание структуры файлов данных:

|НАзвание файла|Расширение|Описание|
|-|-|-|
|dataset| - | Папка с датасетами |
|dataset\genres|.txt| Текстовый файл с перечислением жанров фильмов |
|dataset\movies|.csv| Файл базы данных с перечислением названий фильмов и их жанром |
|dataset\occupation|.txt| Текстовый файл с профессиями/сферами работ|
|dataset\ratings|.csv| Файл базы данных с пользователями, просмотренными ими фильмами, оценками пользователя и временем|
|dataset\tags|.csv| Файл базы данных с фильмом, его тегом и временем|
|dataset\users|.txt| Текстовый файл с ID пользователей и их данными|
|Git_instruction|.md| Файл MarkDown с инструкциями для работы с GitHub|
|README|.md| Файл MarkDown с описанием структуры файлов данных|
|Task01|-| Папка с выполнением задания из файла "task01.md"|
|Task01\genres|.txt| Файл аналогичен самому себе из папки dataset|
|Task01\movies|.csv| Файл аналогичен самому себе из папки dataset|
|Task01\occupation|.txt| Файл аналогичен самому себе из папки dataset|
|Task01\ratings|.csv| Файл аналогичен самому себе из папки dataset|
|Task01\ratings_count|.txt| Файл аналогичен самому себе из папки dataset|
|Task01\README|.md| Файл аналогичен самому себе из папки dataset|
|Task01\sqlite|.txt| Файл аналогичен самому себе из папки dataset|
|Task01\tags|.csv| Файл аналогичен самому себе из папки dataset|
|Task01\users|.txt| Файл аналогичен самому себе из папки dataset|
